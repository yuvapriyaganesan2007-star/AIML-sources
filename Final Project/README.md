
# Student Performance Predictor

A beginner-friendly Machine Learning project that predicts a student's estimated final mathematics grade using historical student data.

## Features
- Loads and explores a real student performance dataset
- Trains a Random Forest Regression model
- Evaluates the model using MAE and R²
- Provides an interactive Gradio web application
- Accepts study time, past failures, absences, and previous grades

## Technologies
- Python
- Pandas
- Scikit-learn
- Gradio
- Joblib
- Google Colab
